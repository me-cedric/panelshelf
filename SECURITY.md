# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | ✅ Active development |

## Reporting a Vulnerability

PanelShelf is in early development and security is taken seriously. If you discover a security vulnerability, please **do not open a public issue**.

Instead, report it privately by emailing the maintainer directly or opening a [GitHub Security Advisory](https://github.com/me-cedric/panelshelf/security/advisories/new).

### What to Include

- **Type of vulnerability** (e.g., XSS, SQL injection, directory traversal)
- **Steps to reproduce**
- **Impact assessment**
- **Suggested fix** (if applicable)

### Response Timeline

- **Acknowledgment** — within 48 hours
- **Initial assessment** — within 5 business days
- **Fix timeline** — depends on severity, typically 7–14 days

Thank you for helping keep PanelShelf and its users safe.
